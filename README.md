# 산업환기 계산기 (PWA)

필요 환기량(㎥/min)과 목표 덕트 반송속도(m/s)를 입력하면 제공된 상용 원형 덕트 규격표 24종 중 이론 직경과 가장 가까운 규격을 추천합니다.

## 포함 파일
- `index.html`: 계산기 화면과 계산 로직
- `manifest.json`: 앱 이름, 아이콘, 설치 및 실행 설정
- `service-worker.js`: 앱 파일 캐시 및 오프라인 실행 지원
- `icons/icon-192.png`: 앱 아이콘(192×192)
- `icons/icon-512.png`: 앱 아이콘(512×512)
- `.nojekyll`: GitHub Pages 설정 보조 파일

## GitHub Pages 배포
1. GitHub에서 새 저장소를 생성합니다. 예: `industrial-ventilation-calculator`
2. ZIP을 압축 해제한 뒤 **폴더 자체가 아니라 폴더 안의 파일과 `icons` 폴더**를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**의 Source를 `Deploy from a branch`로 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 설정하고 Save를 누릅니다.
6. 배포가 완료되면 `https://깃허브아이디.github.io/저장소이름/` 주소로 접속합니다.

## 설치 방법
- Android Chrome: 배포 링크 접속 → 브라우저 메뉴(⋮) → `앱 설치` 또는 `홈 화면에 추가`
- iPhone Safari: 공유 버튼 → `홈 화면에 추가`

브라우저와 운영체제에 따라 설치 메뉴 문구가 다를 수 있습니다. GitHub Pages의 HTTPS 주소에서 설치 기능을 사용할 수 있습니다.

## 오프라인 사용
최초에는 인터넷 연결 상태에서 앱 주소에 접속해야 합니다. 서비스 워커가 앱 화면, manifest, 아이콘을 캐시한 다음부터는 오프라인에서도 계산 기능을 사용할 수 있습니다. 최초 방문 전부터 오프라인 설치하는 것은 지원하지 않습니다.

앱 파일을 업데이트한 경우 서비스 워커 캐시 버전(`CACHE_NAME`)을 변경하면 새 캐시가 생성됩니다. 브라우저가 업데이트를 반영하는 데 약간의 시간이 걸릴 수 있습니다.

## 계산 방식
풍량 Q(㎥/min)를 60으로 나누어 ㎥/s로 변환합니다.

- 이론 직경: `D = √(4Q / (πV))`
- 추천 규격: 이론 직경과 절대 차이가 가장 작은 제공 규격
- 실제 반송속도: `Vactual = Q / Aduct`

## 유의사항
원형 덕트 기준의 계산 보조 도구입니다. 실제 설계·시공 전에는 압력손실, 소음, 재질, 현장 조건 및 관련 설계 기준을 별도로 검토하세요.
